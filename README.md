# SalesGPT.work · Lisa — clickable prototype

A single-page, click-through prototype of SalesGPT.work with Lisa, the sales assistant.

**Prototype only.** Everything runs in the browser on demo data. No real emails are sent, replies and sending are simulated, and "AI" email generation uses templates. Changes are saved in the viewer's own browser (localStorage).

## What's inside
- Dashboard with personal greeting, Lisa's smart suggestions, KPIs and period filters
- Campaigns: on/off switches, ⋯ menu (edit sequence, settings, duplicate, delete), detail pages
- Create Campaign: 5-step wizard with CSV upload, AI sequence generator, sending setup, preview
- Inbox: read/unread, tagging, meeting booked tracking, sequence stop/resume
- Analytics, Email Accounts, Settings, Notifications

## Run locally
Open `index.html` in a browser. No build step.

## Deploy
Static site. On Vercel: New Project → import this repo → Framework preset "Other" → Deploy.
